# ShelterLab 學生地圖素材規格

目前六週地圖已先以可程式控制的 SVG 元件完成，確保四種狀態可以直接由後端資料驅動：

- `locked`：灰階、不可點擊
- `in_progress`：彩色、可點擊、發光
- `pending`：等待審核提示
- `completed`：完成勾選與寶石

## 六週視覺順序

1. 第一週：牧羊犬
2. 第二週：貴賓犬
3. 第三週：柯基犬
4. 第四週：黃金獵犬／拉布拉多類型
5. 第五週：鬥牛犬
6. 第六週：收容所實地參訪入口

## 正式點陣素材替換規格

若之後要把目前概念圖換成最終美術圖，請使用相同尺寸、透明背景的節點素材：

```text
public/student-map/
  map-background.webp
  week-1.webp
  week-2.webp
  week-3.webp
  week-4.webp
  week-5.webp
  week-6.webp
```

建議：

- `map-background.webp`：16:9，建議 1600×900 或 1920×1080；只放環境，不畫鎖頭、完成勾勾、等待審核等狀態。
- `week-1.webp` ～ `week-5.webp`：統一透明畫布，例如 640×520；狗屋與犬隻置中。
- `week-6.webp`：同尺寸透明畫布，內容改為收容所建築／入口。
- 不要把鎖頭、等待審核、完成勾勾、寶石畫進圖片；這些全部由前端程式疊加。

這樣後端只需回傳每週 `status`，不用因學生進度切換整張地圖圖片。
